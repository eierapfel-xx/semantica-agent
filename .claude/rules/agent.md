# 審査支援エージェントを書くときの決まり

- 審査の判定（受理できるか、何が足りないか）は、可能な限りオントロジーへのツール呼び出し（SPARQL、ルール推論、SHACL 検証）の結果から導く。LLM の知識だけで判定させない。
- 1 回の審査ごとに、入力・呼んだツールと引数・参照したノードの IRI・適用したルール・結論をトレースとして記録する。トレースの記録はツールの実装側で行い、LLM の自己申告に頼らない。
- 答えの各主張に、根拠の種類（オントロジーの事実／ルールの判定／LLM の推測）と根拠のノードを付ける。
- トレースの形式（JSON のスキーマ、人が読む報告の形）は仕様書で決め、テストで形式を固定する。
